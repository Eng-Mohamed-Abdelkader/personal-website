## 🛠️ Built With

- **Semantic HTML5:** Structured markup for improved accessibility and SEO.
- **CSS3 Layouts:** Flexbox and CSS Grid for alignable and scalable layouts.
- **Modular Sass (SCSS):** Organized project structure utilizing `@use` directives for clean partial imports and reusable Mixins for media queries.
- **Desktop-First Workflow:** Styled initially for desktop viewports and adapted smoothly down to tablet and mobile screens.
---

## ✨ Key Features

- **Fully Responsive Design:** Seamlessly scales across Desktop, Tablet, and Mobile devices.
- **Modular SCSS Architecture:** Separated style partials imported cleanly using modern Sass directives.
